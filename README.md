# Belas Artes

## Sistema de Controle de Vendas

Projeto prático desenvolvido para estudos em **Análise e Desenvolvimento de Sistemas**, com foco na criação de um sistema simples para controle de produtos, vendas, estoque e análise de informações.

## Sobre o projeto

O **Belas Artes** é um sistema de controle de vendas desenvolvido para uma pequena loja de artigos religiosos e produtos para o lar.

O projeto foi criado como uma aplicação prática para transformar conhecimentos de programação e análise de dados em uma solução funcional para uma situação real de negócio.

## Objetivo

O principal objetivo é permitir o controle básico do processo de vendas, desde o cadastro e controle dos produtos até o registro das vendas e atualização do estoque.

O fluxo principal do sistema é:

**Produto → Venda → Item da Venda → Estoque Atualizado → Histórico → Análise**

## Funcionalidades

* Cadastro e exibição de produtos
* Organização dos produtos por categoria
* Controle de preços
* Controle de estoque
* Registro de vendas
* Controle da quantidade vendida
* Atualização do estoque após uma venda
* Histórico de vendas
* Cálculo do faturamento
* Contagem de itens vendidos
* Análise básica das vendas
* Armazenamento das informações utilizando `localStorage`

## Como executar

1. Clone este repositório ou faça o download dos arquivos.
2. Abra a pasta `BelasArtes` no Visual Studio Code.
3. Abra o arquivo `Loja/Index.html`.
4. Execute o projeto utilizando o **Live Server** ou abra o arquivo diretamente no navegador.
